Shift Change Portal Display Attendees
=====================================

This module extends the shift change portal functionality to display
attendee information (supercooperator and coworkers) in the shift
selection modal.

When a worker wants to change their shift, they can now see:
- The supercooperator's name and contact info (email, phone)
- The list of coworkers already registered for the shift

This helps workers make informed decisions when selecting a new shift.
